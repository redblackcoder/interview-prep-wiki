# Token input and formatted output

## Problem

Read three integers followed by a text token. Output the sum, a space, and that token. The numbers may be separated by spaces or newlines.

## Example

Input tokens 2, 3, 4 and hello produce “9 hello”. The scanner consumes whitespace-delimited tokens, so changing the line breaks leaves the result unchanged.

## Recorded approach

Use whitespace-delimited input so line breaks do not affect parsing.
